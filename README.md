# BorderlessToggle
A simple & lightweight tool that forces borderless fullscreen for games that don’t support it natively.

Perfect for games that don’t support native borderless fullscreen but still want overlay support (Discord, etc).

## Features
- Toggle borderless fullscreen with F11
- Restores original window size when toggled off
- Works on most windowed applications and games
- Extremely lightweight (no background services)

## Controls
- `F11` - Toggle borderless fullscreen
- `Ctrl + Q` - Quit the program

## How it works
This tool removes window borders and resizes the active window to fullscreen, then restores it when toggled again.

## Notes
- Some fullscreen-exclusive games may not support window resizing
- Anti-cheat protected games may block window manipulation
- Best used in windowed mode
- While the program is running, using F11 in YouTube and elsewhere might not work properly, so make sure to quit the program once you stop using it
